# 山海行记

面向 10 岁以上玩家的《山海经》2D 考察游戏。通过观察草木、异兽与山川，阅读原文和儿童释义，完成考察手记。使用 Phaser 4、TypeScript 和 Vite；进度保存在当前浏览器本地。

[直接打开游戏](https://handsun85s.github.io/shanhai-fieldbook/) · [公开源码](https://github.com/handsun85s/shanhai-fieldbook)

手机或电脑浏览器均可打开，无需 GitHub 登录。换设备、浏览器或从旧站点切换到此域名时，记录不会自动同步；收藏上面的游戏链接即可再次访问。

## 当前内容

- 四座可探索山：招摇山、堂庭山、杻阳山、青丘山。
- 草木、石头与异兽插画；狌狌、白猿、鹿蜀、旋龟、九尾狐介绍卡片支持点击互动。
- 可缩放、拖动的十八篇方位总览、南山首段路线和当前山内人物定位。
- 鹿蜀“其音如谣”、旋龟“其音如判木”、九尾狐“其音如婴儿”的录音参照，可播放、停止和静音。
- 键盘、鼠标、小屏触控操作，以及本地考察进度保存。

地图是按篇章方位组织的阅读示意图，轮廓与距离属于编辑布局，不是现代地理或确定的古地图复原。十八篇入口不代表十八篇都已制作成关卡，当前仅开放上述四山。

## 本地运行

需要 Node.js 22 或以上。

```sh
npm ci
npm run dev
```

打开终端打印的本地网址。检查与生产构建：

```sh
npm test
npm run build
```

构建结果在 `dist/`，可交给静态网站服务器托管。不能直接双击源码中的 `index.html` 运行游戏。

## 操作

- WASD / 方向键移动，也可点击地面移动；小屏提供方向按钮。
- 靠近地点按 E 或点“观察”；J 打开手记，M 打开地图，Esc 关闭面板或暂停。
- 地图支持缩放、拖动，点“定位人物”查看当前山内位置；已开放的山可进入探索。
- 打开动物卡片后点击动物触发动作；有声音记录的卡片可播放录音参照。
- 招摇山完成五条观察记录后回营地完成考察；其他山提供各自观察与辨认任务。

## 内容依据与创作边界

参考[《山海经·南山经》原文](https://zh.wikisource.org/zh-hans/山海經/南山經)。正文短引文、儿童释义与游戏演绎分别标注。参考页面包含注文，不能将注文与正文混同。迷榖也写作迷谷，祝余也写作祝馀。

角色、营地、道路、河道形状、动物互动动作和观察规则属于创作。声音是原文比喻的录音示例，不是神兽实录或古代声音复原；婴儿哭声是对“如婴儿”的具体演绎。神奇功效按古籍记载呈现，不作为现实自然知识。

本项目仍是可玩原型，尚未开展儿童试玩。互动以插画移动、摆动和姿态切换为主，尚非完整骨骼动画；录音已完成有效解码、非静音和削波检查，仍需实际听觉体验验收。

## 项目结构

- `src/main.ts`：主场景；`content.ts`、`mountains.ts`：知识内容。
- `src/expeditions.ts`：其他山探索；`worldmap.ts`、`world-data.mjs`：全书图与定位。
- `src/animal.ts`、`sound.ts`：卡片互动与声音；`artwork.ts`：插画展示。
- `public/assets/`：插画及音频；`tests/`：进度和地图规则测试。
- `WORLD_INTERACTION.md`、`EXPANSION.md`、`ART_DIRECTION.md`、`VERIFICATION.md`：实现范围、素材方向及验证记录。
