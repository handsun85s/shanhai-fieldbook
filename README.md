# 山海行记 招摇山

面向 10 岁以上玩家的 2D 考察游戏原型。五条观察记录串起草木辨认、异兽观察、水流辨向和回营地的完整流程。地图与角色由代码绘制，使用 Phaser 4、TypeScript 和 Vite，存档保存在浏览器本地。

## 本地运行

需要 Node.js 22 或以上。

```sh
npm ci
npm run dev
```

打开终端打印的本地地址。生产构建与进度规则测试：

```sh
npm run build
npm test
```

## 操作与流程

- WASD / 方向键移动；也可点击地面移动。小屏提供触控方向键。
- 靠近地点按 E 或点观察。J 打开手记，M 打开地图，Esc 关闭面板或暂停。
- 辨认祝余、迷榖，判断水流方向，在林间观察狌狌白耳，再到静观石停步三秒观察行动。
- 五条记录齐全后，回到西海岸营地，依据水流方向完成考察。
- 地图可标记目标方向；提示提供线索，再次请求时标记位置。暂停菜单中可以确认清除本地进度。

## 内容依据

参考《山海经·南山经》在线文本：
https://zh.wikisource.org/zh-hans/山海經/南山經

`src/content.ts` 将正文短引文、重新撰写的儿童释义和游戏演绎说明分开。参考页夹有注文，正文不能与注文混同。迷榖在参考页写作迷谷；祝余也写作祝馀。狌狌的具体行为动画、等待观察规则、角色、营地、道路和河道形状都是创作，不是古籍描述。神奇功效按书中记载呈现，不作为现实自然知识。

## 当前范围与后续验证

这是短篇可玩原型，尚未达到最初设想的 20—30 分钟内容量，也尚未开展儿童试玩。当前对辨认的引导较直接，下一轮应根据试玩记录增加实际特征比较、分阶段观察与知识迁移任务，而非直接增加山名和怪兽数量。首版没有音效、旁白、联网账号或云存档。

地图采用代码绘制，尚未引入 Tiled 文件工作流；仅在需要反复编辑关卡时再接入。首版将系统收敛到观察和导航，没有复杂叙事依赖。

主要源文件：`src/main.ts`（场景与界面）、`src/content.ts`（知识）、`src/progress.mjs`（存档与完成规则）、`src/style.css`（响应式界面）。

## 第三方依赖

Phaser、TypeScript、Vite 使用 MIT 许可证，完整许可证随 npm 依赖提供。没有复制第三方山海经项目的代码、现代译文或美术素材。项目自身的对外开源许可证尚未指定。
