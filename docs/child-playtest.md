# 10+ 山行试玩记录单

状态：方案已准备，尚未开展真实儿童试玩；自动测试不能证明学习效果。

监护人同意后，由孩子自愿参与，随时可停止。约 20 分钟，不收集姓名、学校、联系方式或录音。记录匿名编号、年龄段、设备与浏览器即可。

1. 不提示操作，让玩家进入杻阳，找到鹿蜀。记录首次移动、迷路和求助的位置。
2. 请玩家指出两个身体特征，再说它们对应的原文。不要替玩家点击答案。
3. 比较鹿蜀与旋龟，允许静音。记录是否混淆“如谣”和“如判木”，以及提示后能否解释。
4. 请玩家找桥过河、展开地图，指出自己和目标的位置。记录遮挡、误触、卡路与加载时间。
5. 完成手记与山行回想。记录独立完成/经提示完成/未完成，保留原话但不含个人信息。
6. 次日用两道新问题回访：把“歌声”写在旋龟卡片上对吗？游戏画出的具体毛色是否一定来自原文？

观察表：任务｜是否独立完成｜卡点｜提示次数｜玩家解释｜设备问题。不要仅以答对率或完成速度评价学习。

改版优先级：先修无法继续与误导原文，再修定位和阅读障碍，最后增加内容。真实手机和扬声器同时检查触控、长时间帧率、音量与突响；本轮未执行这些实机验收。
