# 黏土山海：开发顺序与验收

## 第三批：跨山联系与地图操作

继续深化已有四山，新增三项对照：神兽外形与声音、三山水流、正文/注文/演绎。支持回看依据、逐条反馈、部分选择保存与重新核对，不以对照结果代替实地观察记录。小地图展开直接进入当前山内，河桥共用场景坐标，支持点选目的地寻路及手机大按钮。未扩大山岳数量，未新增无依据的兽声或古地理结论。验收和发布以 progress.md 最新记录为准。

## 本轮进展（2026-11-18 第二批）

已按以下顺序完成开发与自动验收：五种动物和水玉/棪木素材 → 人物三帧动作与四山桥梁寻路 → 特征点击和声音控制 → 四山原文证据、笔记与回想 → WebP、按山加载、手机布局与发布。图集为三帧姿态，不是骨骼动画；地景采用共享碰撞坐标的程序绘制，完整微缩造景质量仍可精修。真实儿童试玩、实际扬声器和真实手机性能尚未完成，见 child-playtest.md。

以下保留原定顺序及验收标准；各阶段状态以本段和 progress.md 最新记录为准。

## 已确认的方向（2026-11-18）

用户在公开 playground 中保存了 **03 · 黏土微缩**，并明确要求采用。已在页面核对“已选这个方向”和保存偏好说明。正式版不再平行开发四套美术；其他样片保留供对照。

核心目标仍是让 10 岁以上玩家通过观察、行动和原文核对认识《山海经》。先把已有四山做深，再增加山岳。游戏人物是虚构的探索者；屏幕上的人物高度与景物比例是可读性设计，不是古籍记载或考古复原。

## 1. 基础画风与人物可读性（本次交付）

- 四山共用暖纸色、苔绿和陶土色界面，圆润按钮、软阴影、手塑地面颗粒。
- 新增独立黏土素材：探索者、普通树木、祝余、迷榖、山中原石；开场、场景、草木图鉴使用同套素材。
- 人物目标高度从招摇 108、其他山 100 世界像素统一为 156；实际显示高度随镜头缩放变化，不把这个数字解释为真实身高或与神兽的实际比例。
- 第二批已替换五种动物和水玉、棪木；全山地形仍未达到样片的完整微缩造景质量。
- 不改变位置坐标、观察距离、进度结构和存档键。小地图继续反映角色脚底的实际坐标。
- 已补基础前后绘制顺序，景物遮挡人物时自动淡化；完整碰撞、可走区域和方向动画留在第 3 阶段。

验收：桌面和 390×844 手机尺寸下角色可辨认；地图与任务不相互遮挡；走近观察点能打开卡片；切山、返回和读取原存档正常。检查图片透明边缘，不能带矩形背景或发光底片。

## 2. 神兽与物产的统一设计（第二批已实现）

先制作“原文特征清单 → 黏土正侧面 → 游戏尺寸 → 详情图”的统一资产规范。先做鹿蜀作为验收样板，再处理狌狌、旋龟、九尾狐和白猿。补齐水玉、棪木及各山独有草石。

逐只保留现有原文依据，例如鹿蜀的马形、白首、虎纹、赤尾，以及旋龟的龟身、鸟首、蛇尾。明确记载的特征不能为了可爱而删掉；没有依据的尺寸、配色细节、习性和动作标注为演绎。尺寸采用有解释的美术规范，不宣称全书有统一比例尺。

验收：场景和卡片是同一只动物；关键部位在手机上也能辨认；九尾狐尾数逐条可数；形态审阅通过后再做动画。

## 3. 人物动作、空间和地图

补人物朝向、待机与行走动作，以及草木前后遮挡、脚底阴影、可行走区域、桥与浅滩。按实测调整镜头，避免人物穿过大树、站在水面或被任务卡挡住。将四山地形逐一做成与选择样片一致的微缩造景。

小地图始终追踪实际脚底坐标；大地图保留山系定位与放大。原文路线示意与游戏场景布局分别标识，不伪装为已经考证的真实古代地理。

验收：鼠标、键盘、手机触控都能找到观察点，角色不因遮挡而丢失；缩放不改变观察目标的位置关系。

## 4. 动物互动与声音

将当前整张图的位移动画升级为适合物种特征的动作：鹿蜀踏步、狌狌伏行/直立、旋龟缓行、九尾狐尾部响应。点击反馈帮助观察特征，避免无意义地重复点击。

声音继续按原文比喻制作与试听，标明录音来源及演绎范围；书中没有指定叫声的对象不补造“原声”。控制突响与音量，静音时仍能完成所有知识任务。

验收：播放、停止、重复点击、关闭卡片和切山都不会留下重叠声音；动作不破坏关键形态；实际扬声器听测另行执行。

## 5. 把已有山岳的探索做深

以一座山的完整循环为单位：发现异常 → 近看/听辨 → 对照原文 → 用证据完成任务 → 写入手记 → 在新的情境中回想。

先打磨招摇与杻阳，再深化堂庭、青丘；避免把三道选择题当作一座山已完成。手记能回看原文、解释和自己的发现；提示逐级提供，不直接替玩家作答。

验收：玩家能说出“我看到了什么，对应哪句原文”，而不只是记住正确按钮位置。现有四山达到这个标准后，再确定下一座山的范围。

## 6. 真实试玩、性能与持续发布

压缩与按需加载大图、检查音频和低性能设备帧率；回归存档、无障碍焦点、静音和减少动态设置。安排 10 岁以上儿童在监护人同意下试玩，记录卡住位置、提示使用、误答纠正和次日回忆；未做实验前不宣称学习效果。

每次可验证的小版本经测试和构建后更新同一个 GitHub Pages 链接，并保留可回退的提交。浏览器手机尺寸模拟不等于真实手机性能验收。
